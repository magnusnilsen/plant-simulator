# Radicle

An interactive encyclopedia of how a plant gets from a dry seed to a seedling.

The science core is Python. The interface is a local web app. Phase 1 covers germination through early seedling growth for Arabidopsis, lettuce, and radish.

See `docs/runbook.md` after the development scripts land, or run:

```bash
make setup
make dev
```

Models, citations, and known limits live in `docs/`.
